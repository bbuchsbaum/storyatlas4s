Keyboard focus order

Proposed runtime contract: twelve tab stops reach the whole instrument. DOM and visual order both follow the task: orient, read, question, inspect. A dense projection has one focusable DOM composite, so it never floods the tab ring.

Specification plate — controls are inert

The painted SVG is aria-hidden="true" focusable="false". One visible DOM twin is the composite tab stop and owns aria-activedescendant; descendants never receive tabindex. Hidden and bundled members remain rows in that twin.

{{ k.key }} {{ k.does }}

Every command has a pointer equivalent. Printable-character shortcuts require a modifier, are scoped to the focused instrument, are remappable, and can be disabled. All shortcuts are suspended in input, textarea, select, and contenteditable contexts.

Matrix twin contract: a visible 11 × 16 DOM grid exposes all cells, including zero, off-source, and Unranked states. Arrow keys move one cell; Home/End move to row edges; Ctrl+Home/Ctrl+End move to grid corners. The active cell announces row and column headers, full AlignState identity, mass, and status.

Semantic transition, with and without motion

The transition shown is Scene → Event on the Atlas, with sentence 5 selected throughout. Both treatments must leave the reader knowing the same three things: the selection survived, the representation changed, and what it changed to.

Morphing is only honest when the correspondence is real. A scene region does not become an event landmark — one contains the other. So the marks crossfade and a tether is drawn, rather than one shape sliding into another.

What replaces the animation

TetherPersistent, not transient. A dashed blue line from the previous mark's position to the new one. GhostThe old mark stays as a dotted outline until focus moves, naming what the new mark descended from. BreadcrumbThe focus bar level chip changes and briefly carries a 2px underline. A state change, not a motion. Announcement“Event level. Selection retained, on-mark.” ReceiptThe layout receipt records both zoom states, so the transition is reproducible from a saved view.

The default treatment carries all five of these too. Motion is the only thing removed — which is the test: if disabling animation loses information, the animation was carrying meaning it should not have been.

Gesture settles on a declared state

A wheel or pinch may feel continuous, but it commits to one of the four narrative levels with hysteresis — it never rests between two. Asynchronous compilation is last-intent-wins, and a superseded result is discarded rather than drawn.

Page navigation is not zoom

Paging the Codex moves the viewport rectangle in the overview and changes nothing else. It is never animated as a level change and never labelled as one. Surface detail and narrative level remain separate controls with separate labels.

Nothing animates on load

There is no entrance choreography anywhere in this design. Motion occurs only as a direct response to a user action, so Animation from Interactions has nothing to suppress that the interface needed.
